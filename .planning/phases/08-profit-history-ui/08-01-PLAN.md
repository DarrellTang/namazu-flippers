# Phase 8 Plan 08-01: Profit History UI

**Created:** 2026-06-13
**Status:** Complete

## Goal

Expose the item-level flip ledger as a compact, read-only profit history view so the player can see whether the flipping workflow is making money without relying on memory.

## Scope

- Add a read-only Profit History window.
- Show realized profit totals for today, 7 days, and 30 days.
- Show open positions with projected remaining profit.
- Show sold history grouped by original buy date.
- Keep projected profit and realized profit clearly separated.
- Load all ledger positions, not only open positions.
- Add Phase 8 source validation.

## Non-Goals

- No editing from the history window; existing correction workflows remain in Positions.
- No retainer/gil/chat/sale-history observability.
- No automatic sale matching or automatic ledger mutation.
