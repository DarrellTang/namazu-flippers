User reported on build > 1.0.26.0 (post-04-07 landing): "The rescan route button is still cut off. I get to Rescan Rou before it's cut off. everything else works." UAT Round 2 Test 1 = ISSUE; Test 2 (Listed checkbox column alignment, GAP-D2) = PASS.

**Why 04-07 didn't close it.** 04-07's fix replaced `const float buttonSpacing = 8f` with `var buttonSpacing = ImGui.GetStyle().ItemSpacing.X`. That was a **real correctness fix** — at scale 1.0 it is a no-op, at scale > 1.0 it makes the reservation track the actual SameLine() gap. But the user-visible bug is upstream of the spacing math. 04-07 addressed the right math on the wrong mechanism.

**Real root cause** (from `.planning/debug/rescan-button-still-cut-off-2.md`):

`DailyRouteWindow.cs:119-132` renders `ImGui.Text("Bought: ... Listed: ...")` THEN calls `ImGui.SameLine()`, THEN measures `avail = ImGui.GetContentRegionAvail().X`. Because the cursor is now mid-row, `avail` is the **remaining row width**, not the full content width. Compounding bug: the literal-pixel button widths (110/80) do not scale with the font, so even if `avail` were correct, "Rescan Route" cannot fit inside a 110px frame at scaled font.

Pixel arithmetic at scale 1.5 (lifted from the debug doc):

| Quantity | Value |
|----------|-------|
| Window content width | ~396px (420 − scaled WindowPadding) |
| "Bought: 0/40   Listed: 0/40" at scaled font | ~195px |
| Cursor X after Text + SameLine | ~207px |
| `avail` from cursor 207 to content edge 396 | ~189px |
| `combinedWidth` = 110 + 12 + 80 | 202px |
| Guard `avail > combinedWidth` → 189 > 202 | **FALSE** |
| Cursor advance | none |
| Settings button: x=207, ends 287 | fits |
| Rescan button: x=299, ends 409 | overflows by 13px → "Rescan Rou" + clip |

Scale 1.0 only works by coincidence (the bought/listed text is small enough at unscaled font to leave room).

**The two-edit fix** (also from the debug doc):

1. **Drop the `ImGui.SameLine()` after the bought/listed Text** so the buttons render on a fresh row and `avail` returns the full content region width.
2. **Scale both button widths by `ImGuiHelpers.GlobalScale`** (Dalamud helper from `Dalamud.Interface.Utility`):
   ```csharp
   var rescanWidth = 110f * ImGuiHelpers.GlobalScale;
   var settingsWidth = 80f * ImGuiHelpers.GlobalScale;
   ```
   Add `using Dalamud.Interface.Utility;` to the using block.
