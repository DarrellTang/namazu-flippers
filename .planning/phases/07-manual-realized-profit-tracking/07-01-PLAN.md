# Phase 7 Plan 07-01: Manual Realized-Profit Tracking

**Created:** 2026-06-13
**Status:** Complete

## Goal

Let the player manually record sold outcomes for durable bought lots, capture actual sale price, and persist tax-adjusted realized profit while preserving the original buy date/session trace.

## Scope

- Add a sale record model under the existing flip-ledger data boundary.
- Extend each flip position with sale history, last sold timestamp, and total realized profit.
- Add a manual sold workflow to the open positions window.
- Compute realized profit with `floor(actual_sale_price * 0.95) - actual_or_planned_buy_price`.
- Support partial closes by decrementing remaining quantity without deleting sold history.
- Register new ledger types in the source-generated JSON context.
- Add Phase 7 source validation.

## Non-Goals

- No retainer, gil-total, chat, or sale-history observation.
- No automatic matching or automatic ledger mutation.
- No profit history dashboard; Phase 8 owns history and aggregation UI.
